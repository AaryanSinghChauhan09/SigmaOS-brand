# SigmaOS-brand

Source visual identity and product assets for SigmaOS. Runtime configuration
belongs in `SigmaOS-config`; this repository owns original source assets and
their attribution and licensing records.

## Current state

The component manifest marks this repository as a scaffold. The tracked
checkout currently contains metadata, a README, a license, and a validation
workflow; no logo, theme, screenshot, or other brand asset is present here.

## Asset requirements

When assets are added, retain editable source files alongside generated
exports, record the creator and license for each third-party input, and keep
exports reproducible from the source where practical. Document formats, color
variants, minimum sizes, and intended use. Do not store machine-specific
runtime settings or application state in this repository.

## Readiness evidence

The metadata validation workflow checks component fields and README presence;
it does not validate artwork, attribution, export quality, or runtime use.
